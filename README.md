# LiScan RL
LIDAR scanning exploration game of your own real life space!

## External Assets & Libraries used:
- URP (Universal Render Pipeline) - Built-in
- Meta XR All-In-One SDK - [assetstore.unity.com](https://assetstore.unity.com/packages/tools/integration/meta-xr-all-in-one-sdk-269657)
- FMOD Audio Engine - [fmod.com](https://fmod.com)
- DOTween Animation/Tweening SDK - [dotween.demigiant.com](https://dotween.demigiant.com/)
- QuickOutline - [assetstore.unity.com](https://assetstore.unity.com/packages/tools/particles-effects/quick-outline-115488)
